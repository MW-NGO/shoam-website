Get involved with a project

For the team

Adding a project should feel like telling a story

No coding, no forms designed by committee. Four steps, clear prompts, and a preview of exactly what visitors will see.

1. Name it plainly

A project name and one honest sentence. If you cannot explain it in a sentence, the project needs a little more thinking — not more words.

2. Add real photos

Photos of people doing the work, not stock images. The studio resizes them automatically, and lets you pick the cover.

3. Publish, then back it up

The site saves your project in this browser so you can see it instantly. Download the backup and paste it into js/local-content.js to make it permanent for everyone.

Photos are stored in the browser, so use a computer you trust. If a project has a lot of photos, the gallery becomes scrollable instead of stretching the page — the same on phones, tablets and desktops.
