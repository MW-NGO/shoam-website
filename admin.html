One-time setup

Connect the content database

The SHOAM-only Supabase project is already connected. If this message appears, js/config.js is missing the SHOAM project URL or browser-safe publishable key.

  1. Open js/config.js and restore the SHOAM URL and publishable key listed in SUPABASE.md.
  2. Confirm supabase/schema.sql and supabase/seed.sql have been run in the SHOAM project.
  3. Confirm the auth URLs from SUPABASE.md are saved in Supabase Authentication.
  4. Create each editor in Authentication → Users → Add user. Keep public sign-up off.

Full instructions: SUPABASE.md. Never put the service_role key in the website.
